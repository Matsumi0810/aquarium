# 〇〇水族館 ウェブサイト

個人制作として作成した水族館のウェブサイトです。

---

## プロジェクト概要

| 項目 | 内容 |
|------|------|
| 制作種別 | 自由制作（個人制作） |
| ターゲット | 子供から大人まで幅広い層 |
| コンセプト | 子供も大人も丸ごと夢中に |

---

## 制作方針

- アニメーションを多用し、子供でも飽きずに楽しめるデザイン
- 大人が見てもわかりやすく、情報を集めやすいレイアウト
- 全体的に角を丸くした柔らかい雰囲気

---

## ページ構成

### トップページ
制作に最も力を入れたページです。

- **MV（メインビジュアル）**　大きく配置しユーザーを引き込む導線を意識
- **クラゲのお知らせ**　当日の情報をリアルタイムで表示。レスポンシブ対応（位置調整に苦労）
- **波のデザイン**　水族館らしさを演出
- **最新情報セクション**　1番伝えたいニュースは大きく、次点のニュースはコンパクトに配置。チンアナゴのアニメーションは個別に秒数を設定しのっぺりしない工夫あり
- **イベント情報セクション**　Swiperを使用したスライダー
- **観光スポットセクション**　チンアナゴが警戒してひょこっと顔を出すアニメーション付き
- **フッター**　バナー制作。「トップに戻る」ボタンはカニのデザインで水族館らしさを演出

### サブページ

| ページ名 | 概要 |
|----------|------|
| 採用情報 | かっちりとした整ったレイアウト |
| 名前応募フォーム | カワウソが送信完了時に出現するアニメーション付き |
| イベントカレンダー | 月をまたいで閲覧可能。今日の日付をリアルタイムで「TODAY」表示 |
| 生物診断 | 独自の仕組みを自分で考えて実装。実際に診断が動作する一押しページ |

---

## レスポンシブ対応

- PC版とスマホ版で画像を切り替え（ジンベイザメの見切れ対策）
- 観光スポット背景画像もスマホ用（縦長）を別途用意して切り替え
- クラゲの位置など、画面幅ごとに細かく調整

---

## こだわりポイント

- チンアナゴのアニメーションは1匹ずつ秒数を個別設定して自然な動きを実現
- 波のデザイン、カニのボタンなど随所に水族館らしさを意識
- イベントカレンダーの「TODAY」表示はリアルタイム反映
- 生物診断ページは仕組みから自分で考えて実装

---

## 振り返り

### 良かった点
- カンプ作成からサイト完成まで一通り経験し、点々と学んできた知識が流れとして理解できた

### 大変だった点
- サイズ感の把握
- 画像の処理
- レスポンシブ対応

### 反省点
- トップページに料金情報を掲載すれば良かった
- 終盤に疲れて最後まで丁寧にこだわりきれなかった
- 作りたいページが間に合わなかった

### 今後の目標
- Swiperや波のアニメーションを自分で組めるようになりたい
- よりスマートに、スピーディに制作できるようになりたい
